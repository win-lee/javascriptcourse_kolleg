Variablen speichern Werte. In JavaScript entstehen sie mit let – einmal, beim ersten Mal. Danach kannst du den Wert beliebig ändern.

02_variablen.js
// Variablen beim (ersten) Erzeugen: let
let x = 5
console.log(x) // <- Variable in Console ausgeben

// einer bestehenden Variablen einen neuen Wert zuweisen
x = 10
console.log(x)

// Wert einer Variable verändern
x = x + 3

// Eine Zahl um genau 1 erhöhen
x++
console.log(x)

// Variablentypen
let zahl = 42 // integer (ganze Zahlen)
let komma = 4.56 // float (Kommazahlen)
let text = "Blabla..." // string (Texte / Zeichenkette)
let wahrheitswert = true // boolean (wahr/falsch)

// Ausgabe von Text & Variablen
console.log("Die Variable komma hat den Wert "+komma)
console.log("In text steckt der Wert "+text+" drin")

🔍 Was du hier lernst

  • let x = 5 erstellt die Variable – später reicht x = 10 (ohne let!)
  • x++ addiert genau 1 – die Kurzform von x = x + 1
  • Text und Variablen hängst du mit + zusammen: "Wert: "+zahl
  • Die Datentypen: integer, float, string, boolean
Achtung: Schreibst du let x = ... zweimal, gibt es einen Fehler („x has already been declared“). let nur beim ersten Mal!
✏️ Deine Aufgabe: Lege Variablen für Name, Alter und Lieblingszahl an. Lass das Alter um 10 erhöhen und gib einen schönen Satz aus.

Jetzt wird es interaktiv: Dein Programm stellt Fragen und der Benutzer antwortet im Terminal. Dafür braucht man die Bibliothek prompt-sync.

03_eingabe.js
// 03_eingabe.js

// Immer wenn man eine Eingabe braucht, dann folgende Zeile
const prompt = require("prompt-sync")()

let name = prompt("Hallo, wie ist dein Name: ")

console.log("Hi "+name)

// Der Befehl Number() macht aus der Eingabe eine Zahl
// (das nennt man Typecast)
let alter = Number(prompt("Wie alt bist du: "))

let gebjahr = 2026 - alter

console.log("Dein Geburtsjahr ist: " + gebjahr)

let in10 = alter + 10

console.log("In 10 Jahren bist du: " + in10)
💻 Terminal – 03_eingabe.js
Hallo, wie ist dein Name: Kim
Hi Kim
Wie alt bist du: 17
Dein Geburtsjahr ist: 2009
In 10 Jahren bist du: 27

🔍 Was du hier lernst

  • const prompt = require("prompt-sync")() gehört an den Anfang jeder Datei mit Eingaben
  • prompt("Frage: ") stellt die Frage und liefert die Eingabe zurück – immer als String!
  • Number(...) verwandelt den String in eine Zahl, damit du rechnen kannst
Achtung: prompt ist eine externe Bibliothek – einmal pro Projekt installieren: npm install prompt-sync im Terminal. Vergisst du das, kommt die Meldung „Cannot find module 'prompt-sync'“.
Merke dir: Mit prompt("Alter: ") und der Eingabe 17 bekommst du den String "17" – erst Number() macht die echte Zahl 17 daraus. Sonst rechnet JS plötzlich mit Text!
✏️ Deine Aufgabe: Frage zwei Zahlen ab und gib ihre Summe aus – genau das ist die Übung rechner1.js weiter unten!

Dein Programm soll entscheiden: Kommt die Person in den Club oder nicht? Dafür gibt es die Abfrage mit if, else if und else.

04_abfrage.js
// 04_abfrage.js

// Abfrage = Entscheidung = Verzweigung = Überprüfung
const prompt = require("prompt-sync")()

let alter = Number(prompt("Wie alt bist du: "))

// Mit if kann man eine Überprüfung machen
if (alter < 16) {
    console.log("Kommsch da nit rein.")
}
else if (alter <= 18) {
    console.log("Aber keine harten Drinks.")
}
else if (alter == 20) { // wenn man genau gleich prüfen will: ==
    console.log("Happy 20")
}
else {
    console.log("Viel Spaß!")
}

🔍 Was du hier lernst

  • JavaScript prüft von oben nach unten – die erste wahre Bedingung gewinnt, der Rest wird übersprungen
  • == vergleicht auf Gleichheit, <, >= usw. vergleichen Zahlen und Text
  • else greift, wenn keine Bedingung stimmt
Merke dir: Die Reihenfolge ist entscheidend! Prüfe immer von eng nach weit – hier ist das schon eingebaut: erst < 16, dann <= 18, dann == 20. Mit alter = 17 gewinnt übrigens „Aber keine harten Drinks.“ – die erste wahre Bedingung gewinnt, der Rest wird übersprungen.
Achtung: Vergiss Number() bei der Eingabe nicht! Mit dem String "20" mag der Vergleich zufällig klappen – aber jede Rechnung danach geht schief.
✏️ Deine Aufgabe: Schreibe eine Noten-Abfrage: 1 → „Sehr gut“, 2 → „Gut“, 3–4 → „Bestanden“, 5–6 → „Nicht bestanden“.

Manchmal müssen mehrere Dinge gleichzeitig stimmen – Benutzername und Passwort. Dafür verkettest du Bedingungen mit logischen Operatoren.

05_abfrage2.js
// 05_abfrage2.js

const prompt = require("prompt-sync")()

// Passwort Überprüfung
// richtiges Passwort: admin
// richtiger Username: user

let username = prompt("Gib deinen Usernamen ein: ")
let pw = prompt("Gib dein Passwort ein: ")

// && bedeutet UND, das heißt BEIDE Überprüfungen müssen zutreffen
if (pw == "admin" && username == "user") {
    console.log("Korrekt")
}
else {
    console.log("Falsch")
}

🔍 Was du hier lernst

  • && (UND): beide Bedingungen müssen wahr sein
  • Beide Prüfungen stehen in einer Klammer – das Ergebnis ist ein einziges wahr/falsch
Merke dir: && verlangt, dass beide Bedingungen wahr sind – Passwort und Username müssen stimmen. Fehlt auch nur eins, greift der else-Zweig.
✏️ Deine Aufgabe: Baue eine Alters-UND-Wohnort-Abfrage: „Zutritt nur, wenn du mindestens 18 bist und aus Wien kommst“.

Kommazahlen sind oft grauslig lang. Mit toFixed() und den Math-Funktionen bringst du sie in Form – unverzichtbar für Preise und Ergebnisse.

06_zahlen-formatieren.js
// 06_zahlen-formatieren.js

// Eine Zahl auf bestimmte Kommastellen genau: .toFixed(ANZAHL)
console.log( zahl.toFixed(5) )

// auf ganze Zahlen runden

// "kaufmännisch" runden
console.log( Math.round(zahl) )

// immer AUFrunden
console.log(Math.ceil(zahl))

// immer ABrunden
console.log(Math.floor(zahl))

15.44465
15
16
15

🔍 Was du hier lernst

  • zahl.toFixed(5) → genau 5 Nachkommastellen: 15.44465
  • Math.round() – kaufmännisch runden (ab .5 auf)
  • Math.ceil() – immer aufrunden, Math.floor() – immer abrunden
Merke dir: Math.floor() brauchst du gleich wieder – für Zufallszahlen in Lektion 07!
✏️ Deine Aufgabe: Frage einen Preis ab und gib ihn schön formatiert mit 2 Nachkommastellen aus, z. B. „Das kostet 19.99 €“.

Mit Math.random() erzeugt JavaScript Zufallszahlen – die Basis für Spiele wie das Zahlenraten. Die Formel sieht tricky aus, ist aber ein festes Muster.

07_zufallszahlen.js
// 07_zufallszahlen.js

// Zufallzahlen in Js mit Math.random()
let zuza = Math.floor(Math.random()*10)+1
console.log(zuza)

let zuza2 = Math.floor(Math.random()*200)+1
console.log(zuza2)

🔍 Die Formel Schritt für Schritt

  • Math.random() liefert eine Kommazahl zwischen 0 und 1 (z. B. 0.7284…)
  • * 10 macht daraus etwas zwischen 0 und 9.99…
  • Math.floor() schneidet die Kommastellen ab → 0 bis 9
  • + 1 schiebt alles hoch → 1 bis 10 ✓
Merke dir: Das Muster ist immer gleich: Math.floor(Math.random()*OBERE_GRENZE)+1 liefert eine ganze Zahl von 1 bis OBERE_GRENZE. Einen Würfel baust du mit *6.
✏️ Deine Aufgabe: Simuliere einen Würfel: gib bei jedem Start eine zufällige Zahl von 1 bis 6 aus.

Etwas 10-mal wiederholen? Dafür gibt es die for-Schleife – definiert über drei Parameter.

08_for-schleife.js
// 08_for-schleife.js

// FOR Schleife (definiert mit 3 Parametern - getrennt durch ;)
// 1. Parameter: Startwert (wo zählt die Schleife los?)
// 2. Parameter: Endwert/Abbruchbedingung (wie weit zählt die Schleife?)
// 3. Parameter: Schrittweite (in welchen Schritten zählt die Schleife?)

for (i=1; i<=10; i++) {
    console.log("FOR Schleife "+i)
}
💻 Terminal – 08_for-schleife.js
FOR Schleife 1
FOR Schleife 2
...
FOR Schleife 10

🔍 Was du hier lernst

  • Startwert: i=1 – die Zählvariable beginnt bei 1
  • Abbruchbedingung: i<=10 – läuft, solange i kleiner oder gleich 10 ist
  • Schrittweite: i++ – erhöht i nach jedem Durchlauf um 1
Merke dir: Einzige Besonderheit: die Variable i wird hier ohne let deklariert. Sauberer wäre let i=1 – beide Varianten funktionieren in unseren Programmen.
✏️ Deine Aufgabe: Zähle von 1 bis 20 – und dann rückwärts von 10 bis 1 (Tipp: Schrittweite i-- statt i++).

Die while-Schleife hat nur einen Parameter: die Abbruchbedingung. Sie läuft, solange etwas wahr ist – ideal, wenn du die Anzahl noch nicht kennst.

09_while-schleife.js
// 09_while-schleife.js

// WHILE Schleife (nur 1 Parameter)
// 1 Parameter: Abbruchbedingung

let i=1

while (i<=10) {
    console.log("WHILE Schleife "+i)
    i++
}

🔍 for oder while – wann was?

  • for: wenn du weißt, wie oft die Schleife laufen soll („zähle von 1 bis 10“)
  • while: wenn du nur eine Bedingung kennst („solange der Tipp falsch ist“)
Achtung: Bei while steht i++ im Schleifenkörper – vergisst du es, bleibt die Bedingung für immer wahr: Endlosschleife! Abbrechen kannst du im Terminal mit Strg + C.
✏️ Deine Aufgabe: Gib mit einer while-Schleife die Zahlen 20, 18, 16, … bis 2 aus (Tipp: Schrittweite i = i-2).

Das wichtigste Muster für interaktive Programme: Die Schleife läuft immer wieder – bis der Benutzer sagt, dass Schluss ist.

10_while-mit-frage.js
// 10_while-mit-frage.js
const prompt = require("prompt-sync")()
// WHILE Schleife mit Frage ob man von vorne starten möchte
let nochmal = "ja"

while (nochmal == "ja") {
    console.log("Ich bin ein Pseudo-Programm...")

    nochmal = prompt("Willst du nochmal starten? (ja/nein): ")
}
💻 Terminal – 10_while-mit-frage.js
Ich bin ein Pseudo-Programm...
Willst du nochmal starten? (ja/nein): ja
Ich bin ein Pseudo-Programm...
Willst du nochmal starten? (ja/nein): nein

🔍 Was du hier lernst

  • Die Variable nochmal startet mit "ja" – so läuft die Schleife mindestens einmal
  • Am Ende des Schleifenkörpers wird neu gefragt – antwortet der Benutzer „nein“, endet die Schleife
  • Dieses Muster steckt in kopfrechnen_2b.js und zahlenraten.js!
Merke dir: Das ist der Bauplan für fast jedes Spiel und jedes interaktive Programm: Schleife → Programmteil → Frage am Ende.
✏️ Deine Aufgabe: Bau einen Mini-Chatbot: Er stellt eine Frage, antwortet mit einem Witz – und fragt dann, ob er noch einen erzählen soll.

Tipp: Für 2a: eine for-Schleife um die Aufgabe (Lektion 08) und Zufallszahlen (Lektion 07). Für 2b: das „Nochmal?“-Muster aus Lektion 10!
kopfrechnen_2a / 2b – Kernidee
// kopfrechnen_2a.js – 3 Aufgaben mit for:
for (let n=1; n<=3; n++) {
    let a = Math.floor(Math.random()*10)+1
    let b = Math.floor(Math.random()*10)+1
    let tipp = Number(prompt("Die Aufgabe: "+a+" + "+b))
    if (tipp == a+b) console.log("richtig!")
    else console.log("falsch – korrekt: "+(a+b))
}

// kopfrechnen_2b.js – weitermachen? (Lektion 10):
let weiter = "ja"
while (weiter == "ja") {
    // ... eine zufällige Aufgabe stellen und prüfen ...
    weiter = prompt("Noch eine Aufgabe? (ja/nein): ")
}

Aufgabe: Das Programm soll sich eine zufällige Zahl „ausdenken“, zur Eingabe eines Tipps auffordern und Feedback geben, ob der Tipp richtig oder falsch war – bei falschem Tipp einen Hinweis („höher“ oder „niedriger“), beim richtigen Tipp die Anzahl der benötigten Versuche ausgeben.

Tipp: Alles zusammen: Zufallszahl (Lektion 07), while-Schleife bis der Tipp stimmt (Lektion 09), Versuchszähler mitzählen (versuche++) und if/else für den Hinweis (Lektion 04).
zahlenraten.js – Kernidee
let zufall = Math.floor(Math.random()*100)+1
let versuche = 0
let tipp = 0

while (tipp != zufall) {
    tipp = Number(prompt("Dein Tipp: "))
    versuche++

    if (tipp == zufall) {
        console.log("Richtig! Du hast "+versuche+" Versuch(e) gebraucht")
    }
    else if (tipp < zufall) {
        console.log("Höher!")
    }
    else {
        console.log("Niedriger!")
    }
}
